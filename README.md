# UE5-ThirdPersonAction

基于 Unreal Engine 5 开发的第三人称动作游戏练习项目。

本项目用于学习 Unreal Engine 5 游戏开发流程，同时熟悉 Git 与 GitHub 的版本控制和项目管理方式。

---

## 🎮 项目简介

这是我的 UE5 第三人称动作游戏原型项目。

项目基于 Unreal Engine 5 Third Person Template 创建，并计划在此基础上逐步开发角色控制、战斗系统、敌人 AI、动画、UI 等功能。

通过这个项目，我将实践从 **UE5 基础学习 → 游戏系统开发 → Demo 制作** 的完整流程。

---

## 🛠 开发环境
