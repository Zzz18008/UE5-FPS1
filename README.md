# UE5-FPS1

A first-person FPS game prototype developed with Unreal Engine 5.

## About

This project is my Unreal Engine 5 FPS learning and development project.

The goal is to learn Unreal Engine 5 fundamentals through practical development and gradually build a complete playable FPS prototype.

The project will cover gameplay programming, Blueprint scripting, player movement, shooting mechanics, weapon systems, UI, animation, effects, enemy AI, and level design.
